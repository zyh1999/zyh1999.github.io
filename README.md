# Yihe Zhou — academic homepage

Public site: https://zyh1999.github.io/

A lightweight, responsive academic homepage. No framework, build step, analytics, or external font service is required.

## Edit

- `index.html`: biography, research interests, publications and links.
- `assets/site.css`: layout, responsive styles and print presentation.
- `assets/site.js`: progressively enhanced publication filters. All papers remain visible without JavaScript.
- `assets/yihe-zhou.webp`: existing professional portrait from the Agent Lab people page.

For local preview, run `python3 -m http.server 8000` and open `http://localhost:8000`.

GitHub Pages serves the `main` branch from `/ (root)`; `.nojekyll` keeps the site static.

## Content sources

Publication titles and author lists come from linked papers and proceedings, with the applicant's Google Scholar records as a cross-check. NeurIPS 2026 status follows the paper's camera-ready arXiv record. Current research directions are described as interests; unpublished experiments are not presented as established results.

The previous Hexo blog and its dated articles, archives, tags and theme assets were removed at the owner’s request. Earlier versions remain recoverable through Git history.
